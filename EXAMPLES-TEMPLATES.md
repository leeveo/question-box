2. 💍 "Un conseil pour leur vie de couple ?"
3. 🔮 "Quelle est ta prédiction pour leur avenir ensemble ?"
4. ❤️ "Décris leur amour en 3 mots"
5. 😢 "Quel moment t'a le plus ému aujourd'hui ?"

## 🎨 Conseils d'Utilisation

### 📊 Combinaison de Templates

Vous pouvez combiner plusieurs templates pour un événement complexe :

**Exemple : Mariage + Remerciements**
```
Questions 1-5 : Template Mariage (messages pour les mariés)
Questions 6-10 : Template Remerciements (gratitude envers les familles)
```

**Exemple : Entreprise + Rétrospective**
```
Questions 1-4 : Template Entreprise (vie de l'équipe)
Questions 5-8 : Template Rétrospective (bilan personnel)
```

### ⚙️ Personnalisation

Après ajout d'un template, vous pouvez :
- ✏️ Modifier le texte des questions
- 🔄 Réorganiser l'ordre
- ➕ Ajouter des questions supplémentaires
- ❌ Supprimer celles qui ne conviennent pas

### 🎯 Choix de la Durée

| Type de question | Durée recommandée |
|-----------------|-------------------|
| Question courte (nom, mot) | 5-6 secondes |
| Question moyenne (souvenir) | 8-10 secondes |
| Question complexe (réflexion) | 12-15 secondes |
| Question émotionnelle | 10-12 secondes |

### 🎤 Ton et Ambiance

## 🔄 Workflow Recommandé

```
1. Identifier le type d'événement
   ↓
2. Cliquer sur le template correspondant
   ↓
3. Prévisualiser les 8 questions ajoutées
   ↓
4. Personnaliser si nécessaire
   ↓
5. Ajuster la durée de réponse
   ↓
6. Ajouter une image de fond (optionnel)
   ↓
7. Créer le projet
   ↓
8. Partager le QR code aux participants
```
